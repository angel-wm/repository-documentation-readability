# Repository Documentation Readability

A lightweight convention for readable, mobile-friendly repository documentation.

The convention defines how to choose between prose, Markdown tables,
numbered procedures, text trees, code blocks, and Mermaid diagrams while
preserving project semantics and keeping documentation readable on both
mobile and desktop.

The normative definition lives in [SPEC.md](SPEC.md).
